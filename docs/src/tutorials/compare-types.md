# Compare file types across folders

**Goal:** see which kinds of files make up each folder, for example whether a project folder is
mostly video, images or caches.

## Steps

1. Scan the parent folder.
2. Look at the treemap with **Color by: Type**: each folder's region is coloured by the files in
   it, so a folder that is mostly video is mostly one colour. The **File types** tab tells you
   which colour is which.
3. **Click an extension** in the File types tab to highlight it. You can now see, at a glance,
   which folders contain that type and how much of each folder it fills.
4. For numbers, turn on a filter such as **Show: 🖼 Images** and choose **Show matches only**.
   The file manager now shows, for every folder, the size, share and file count of just the
   matching files, so you can compare folders directly. (The File types tab and the match count
   cover the whole scan.)
5. For the complete type breakdown of one folder, scan that folder on its own (type its path and
   press **Enter**) and read the **File types** tab.
6. Use the **Sizes** tab with a **Show:** category to compare how big those files are in the
   folder on the map.

## Tips

- The **Sunburst** view colours folders by top-level branch and files by type, which makes it easy
  to compare a few large folders side by side.
- **Show matches only** recalculates percentages for the matching files only, which is useful
  for "what share of the images is in each folder?".
