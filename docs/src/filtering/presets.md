# Presets and recent filters

The **⏷** button next to the Custom filter box opens a menu for reusing patterns.

## Recent

Every pattern you apply with **Enter**, pick from the menu, or leave the box after typing is
added to **Recent** (the last 12, newest first). Click one to use it again. **Clear** empties the
list.

## Presets

To keep a pattern permanently under a name of your own:

1. Type the pattern in the Custom box.
2. Open **⏷**, type a name in **Preset name** (for example `Render frames, no previews`), and
   press **Save as preset**. If you leave the name empty, the pattern itself is used as the name.
3. The preset appears under **Presets** at the top of the menu. Click it to apply it; hover over it
   to see its pattern.

Saving a preset with the name of an existing one replaces it. **🗑** deletes a preset.

## Options

The menu also has the matching options, which apply to every pattern:

- **Case-sensitive** (the same as the **Aa** button).
- **Match any term (OR)** or **Match all terms (AND)**. See
  [Match all terms](syntax.md#match-all-terms-and).

## What is remembered

Recent patterns, presets, the matching options and the **Highlight** / **Show matches only**
choice are saved when dirmap closes and are there next time. The pattern in the box isn't: dirmap
always starts with no filter.
