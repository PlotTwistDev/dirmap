# Licensing

Filescape is being released as **Filescape**. Browsing your files and the disk map are free for
good: you can look around and navigate by hand. The rest is **Filescape Professional**, unlocked by a licence. Open
**⚙ Settings > Licensing**, or **Help > Licence**, to see your licence or enter one.

## Free and Professional features

| Free | Filescape Professional |
|---|---|
| The Files workspace: browsing, tabs, the address bar, the filter box, the preview, opening files, copy, move, rename, delete and New | Filtering by type or size: the **File types** buttons in the **Filters** panel and the Files **Show** menu (except **Applications**), **Larger than** and **Smaller than**, picking a range on the size chart, and highlighting a file type on the map |
| Scanning, the treemap, the sunburst, the directory tree and the File types list | The **Custom** filter, filter presets and recent filters |
| Scan exclusions | Finding numbered sequences, and the sequence player |
| Applications: recognising them, their own icons, launching, Show Package Contents, their details, their size on the map, and the **Applications** filter and total | |
| Cloud files: sizes on disk, status icons, the storage breakdown, never downloading without asking, and freeing up or keeping one file at a time | Cloud management: the **Stored** filter, the **Reclaimable** view, and freeing up or keeping folders and several items at once |
| | The Remote workspace: connecting to servers and starting transfers |
| | Batch rename, Compare Folders, Compare Scenes (two splat scenes), splat training project breakdowns and timelines, and the duplicate finder |
| | Browsing and extracting archives, saved searches and snapshots |
| The AI Models workspace: finding models, their details and architecture, copies and unused downloads, health checks, will-it-run estimates, and deleting or moving one model at a time | Managing models in bulk: moving several models at once, removing copies automatically and scheduled maintenance |
| Ask AI: downloading a model when you agree to it and running it on this computer, chat, questions about a file, summaries, image descriptions, search by meaning and a suggested name for one file | Processing many files with AI at once: batch descriptions, AI-suggested batch renaming and automatic organising |
| The Model Lab: the tokenizer, token probabilities, sampling controls, a basic benchmark, looking inside a model by hand, and optional research extensions | Quantising models, automated benchmarks and experiments, experiment history, reusable workflows and reports |

AI features that are free have no limits: any model size, any number of models, local runs with
your graphics card, and as many experiments as you like. Filescape never charges for AI that runs on
your own computer. In short, doing something yourself is free; having Filescape do it for you,
many at a time or on a schedule, is Professional.

Without a licence, a filter that's already on can still be turned off or cleared.

Professional features are checked only when you **start** something. Work that's already running,
such as a copy, a transfer, a batch rename or an extraction, always finishes, even if a licence
expires halfway through. Retrying or resuming a transfer is never checked. When a feature needs a
licence, a box says so and offers **Enter Licence Key…**, **Purchase Perpetual Licence** and
**Not now**. Your files, settings and saved data are never touched.

## Evaluation

For the first 15 days after Filescape is first started on a computer, every feature is unlocked.
In the last week a line at the top of the window counts the days down. Afterwards the free features carry on
as before. The start date is kept in the system keychain as well as in Filescape's own files, so
a temporary licence ending never starts the evaluation again.

## Licence types

| Type | What it does |
|---|---|
| **Perpetual** | Never expires. It covers every version released while its updates last (12 months from purchase), and can be active on up to 3 computers at once. |
| **Temporary** | Full access for a set time: usually 30 days from the first time it's activated, or until a fixed date. It can't be renewed; when it ends you can enter another licence or buy a perpetual one. |

If you have both, the perpetual licence is used. When a temporary licence expires, Filescape
shows **Your temporary Filescape licence has expired**, Professional features ask for a licence
again, and everything you'd saved is kept.

## Updates

Each time Filescape starts it asks filescape.app for the newest version (in the background, so
it never slows the start). When there's a newer one, a notice at the top of the window says
**Filescape 0.3.0 is available** and what it means for your licence:

| Notice | Meaning |
|---|---|
| **Your licence covers it.** | Your perpetual licence's updates include the new version: install it and everything stays unlocked. |
| **Your licence's updates ended on …** | The new version was released after your updates ended. You can still install it, but only the free features would be unlocked there. The version you have keeps working with everything unlocked, as long as you like. **Buy a licence** opens the shop. |
| **It's a free update.** | You're using the free features, the evaluation or a temporary licence, which work the same in the new version. |

**Download** gets the new version for your system and **What's new** opens the release notes.
**✖** hides the notice until Filescape next starts. Being offline, or the check failing, never
locks or delays anything: there's simply no notice.

The check sends no serial number, computer identifier or anything about your files: it's an
ordinary request for the latest version number, and the answer is signed by the licence server so
it can't be forged. Turn it off with **⚙ Settings > General > Updates > Check automatically**. **Check now**
on the same page checks straight away and shows when the last check succeeded.

## Entering a licence

Type or paste the serial number (it starts with `FST-` for a temporary licence or `FSP-` for a
perpetual one) into the box and press **Activate**. Spaces, dashes and the case of letters don't
matter, and a mistyped serial is caught at once without using an activation.

The status screen then shows the licence type, the expiry date (or the end of updates for a
perpetual licence), the days remaining, and how many computers are active (perpetual) or activations used (temporary). **Licence
Details** lists the registered owner, licence ID, serial number, and the dates issued, activated
and expiring.

| Button | Effect |
|---|---|
| **Copy Serial** | Copies the serial number to the clipboard. |
| **Export Licence ⏷ > Licence Certificate (signed)…** | Saves a `.filescape-licence` file signed by Filescape, as proof of purchase. **Verify a licence certificate** checks one. |
| **Export Licence ⏷ > Licence Details (text)…** | Saves the details as plain text. |
| **Deactivate This Computer…** | Ends the licence on this computer. For a perpetual licence this frees the computer's place for another one; a temporary licence's activation isn't given back. |
| **Purchase Perpetual Licence** | Opens the Filescape website. |

## Activations

A **perpetual** licence can be active on 3 computers at once.

- Starting Filescape again, restarting the computer or activating again on the same computer
  doesn't take another place.
- To move to a new computer, deactivate the old one (**Deactivate This Computer…**), or sign in at
  `account.filescape.app` with the email you bought with and press **Release** next to it. Its
  place is free straight away.
- The first computer you release in a week frees its place at once. Release more in the same week
  and those keep their place for 7 days, so a licence can't be passed round many computers.
- If an old computer is lost or broken and you can't sign in, ask Filescape support.

A **temporary** licence has 3 **activations**, ever: each new computer uses one.

- Deactivating a computer doesn't give its activation back. For a temporary licence with 3
  activations: activate on computer A (1 used), deactivate A, activate on B (2 used), then on C (3
  used). A fourth computer is refused, even if A, B and C are all deactivated.
- A temporary licence's expiry date is set by its first activation and never moves.

If a temporary licence runs out because a computer was replaced, ask Filescape support: they can reset its activations.

## Offline activation

For a computer without internet access, open **Offline activation**, enter the serial and choose
**Save Request…**. Take the request file to any computer that's online, upload it at
`account.filescape.app/activate`, and bring the response file back with **Import Response…**. It
counts towards the same limit as activating online (release it at `account.filescape.app` when you're done with that computer), and the response only works on the computer
that made the request.

## Checks and the clock

Licences are signed by Filescape's licence server, so changing the files Filescape keeps doesn't
unlock anything. Once a week, when the computer is online, Filescape checks that the licence is
still valid. A failed check (no internet, server down) never locks anything.

Time-limited licences go by the computer's clock. If the clock is set back more than two hours
before a time Filescape has already seen, time-limited licences pause and the banner says
**This computer's clock is behind**. Set the clock right, or go online so Filescape can check the
time. Perpetual licences don't depend on the clock.

A computer kept offline for good can't be checked, so a determined person could keep a temporary
licence going there by changing the clock and Filescape's files together. The weekly check catches
this as soon as the computer goes online.
