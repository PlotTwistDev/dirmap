What's new

Every version of Filescape and what changed in it. This is the same list as Help > What's new in the app.

Next versionVersion 0.2.0Version 0.1

Next version not released yet

Being worked on now. These changes arrive in the next release; the download is still the latest released version.

Eject drives

  • External drives, USB sticks, SD cards and disk images can be ejected from Filescape on macOS, Windows and Linux: the ⏏ button by a drive in the sidebar and in Computer, or Eject on its right-click menu. Disk images stored on a drive are ejected first, and when an app is still using the drive Filescape names it, with Try Again and Force Eject.

Where a database's space goes

  • SQLite previews show how much of the file each table takes, run the tabs largest first and open on the largest table, so a big database whose first table is empty no longer looks empty. Search-index tables are counted with their index, and the details name the three largest tables and any unused space a VACUUM would give back.

Easier to read maps

  • Display > Detail on the map: Minimal, Balanced or Detailed names and sizes on the tiles, with shares at Detailed. Remembered, and shared by Storage Analysis and the dock.
  • The clicked item's ring now reads on any tile colour, and a zoomed-in map shows how far it's zoomed.

One map, two places

  • The analysis dock in Files has the same toolbar as Storage Analysis, in a compact form: Treemap / Sunburst, Follow, Colour, and display options under ⋯. It keeps its own colours.
  • Follow can now follow the left or right pane as well as the active one or the selection, or be Locked on one folder.
  • Open in Storage Analysis takes the dock's folder, view, colours and selection with it, and Reveal in Files (on Storage Analysis's right-click menu and Preview pane) goes the other way.
  • The dock's information line says how much of a folder is only in the cloud.

Panes that make room for the map

  • The Preview pane beside the Storage Analysis map has Preview and Details tabs, opens by itself when you click a tile and folds away when nothing is selected. Pin it to keep it open. It remembers its width and tab, and has Reveal in Files to jump to the item in the Files workspace.
  • The Insights panel (File types, Sizes, Changes, Duplicates, Sequences) folds away too, with Alt+I (⌥I). Folded panes leave a narrow rail at the window's edge with a button for each.

Totals, legend and storage under the map

  • Under the Storage Analysis map, a strip of totals: On disk, Logical size, Cloud only, Reclaimable, Files, Folders and, with a filter on, Matching. The total the map is sized by is highlighted, and clicking another switches to it. Cloud-only data is never counted as on this computer.
  • A new legend shows each type's colour, size and share. Point to a type to see where those files are on the map, click to highlight them, and Ctrl+click (⌘-click) to highlight several. All N types lists every type, sortable by size, count or name. The Files dock uses the same legend.
  • Details and Storage open the scan's details and the cloud storage breakdown, now a full-width bar with Reclaimable beside it. The status bar keeps to what's happening.

A calmer Storage Analysis toolbar

  • The controls above the map are one row now: Treemap / Sunburst, a Size menu, a Colour menu, Filters, a search box and a Display menu. Back, Forward, Up, Whole map and Zoom to selection sit beside a breadcrumb of the folder on the map, whose last part opens the scan controls. In a narrow window, menus fold into ⋯ instead of wrapping.
  • Filters moved into a Filters panel that stays open while you use the map: file types, where files are stored, size presets and ranges, and a new Last changed filter (last 7 or 30 days, last year, or untouched for over a year or five years).
  • Each filter that's on shows as a removable chip under the toolbar, with Highlight / Only matches, the match count and Clear all. With no filter on, the row is hidden.

Storage Analysis keeps up with changes

  • Files added, changed or removed after a scan now show in Storage Analysis by themselves: a download appears in the map a second or so after it finishes, and a file deleted in another app disappears. Downloads still being written (.crdownload, .part, Safari's .download) are left out until they're done. Turn it off under Settings > General > Keep up with changes.

Gaussian splat scenes

  • SPZ files (every version) and PLY splat scenes now preview in Files and Storage Analysis: the splats drawn for real on the graphics chip, to turn, move and zoom about, with their view-dependent colour (points where the graphics can't), the splat count, colour detail, size and the graphics memory it would need, and checks for invisible, oversized or stray splats. PLY files are told apart by their header, so meshes still show as models, and PLY point clouds now show their points instead of "no faces to show".
  • More splat formats: compressed PLY (PlayCanvas and SuperSplat), SPLAT, KSPLAT, SOG (bundled or loose), GLB files with Gaussian splats, and web pages exported from SuperSplat, whose embedded scene is read without running the page.
  • Splat thumbnails in Icons view and on map tiles are drawn as real splats on the graphics chip, and map tiles show the format and splat count. Quick Look has ◀ and ▶ buttons for the previous and next file, and a camera button on a splat scene saves the view as a PNG of up to 4K.
  • A splat scene's preview can show its splats as outlines or centres, or in false colour by opacity, size, crowding or distance; Problems picks out the splats the checks found, including a new check for floaters. There's also a box round the main body, a field of view control, and W A S D to move about. Turning a scene is smoother: pictures arrive while you drag, at half size, instead of only when you stop.
  • The Storage optimiser under a splat scene's details measures how big it would be as SPZ, compressed PLY or standard PLY, and saves a converted copy, read back and checked, next to the original, which is kept. As SPZ, a trainer's PLY is often about a tenth of the size.
  • Compare Scenes (Professional): select two splat scenes and right-click to see them side by side, split by a line you drag, or as their difference, turning together, with how alike the pictures are and both scenes' details side by side.
  • Splat scenes that change over time play in the preview: 4D scenes (Space-Time Gaussians Lite PLYs) and numbered splat files in a folder, with a play button and a slider under the picture.
  • Big splat scenes kept in chunks preview: streamed SOG (lod-meta.json), and XGRIDS LCC and LCC2, showing the most detailed level that fits. Chunks only in the cloud are counted, never downloaded.
  • Splat training folders preview as a summary of what trained them, the photos and starting points used, and the scenes saved along the way. Professional adds what takes the space and a timeline of each saved scene by training step, with its splat count.

The AI Models workspace

  • 🖴 Storage shows how much space AI models take, by app, and finds what can be freed: Ollama downloads no model uses, unfinished downloads, older Hugging Face versions and copies. Copies on the same drive can be shared as one file (a hard link), so every app keeps working. Each item lists what it changes, with one confirmation. Right-click a model and choose Move to Trash… to remove it properly: for Ollama, as ollama rm would. Move to another drive… moves an app's whole model folder and leaves a link, so the app finds its models as before (Professional). Shrink (quantise)… in a model's right-click menu makes a smaller copy (Q8_0 to Q2_K), keeping the original (Professional).
  • 🔬 Lab shows what a model would write next and how sure it is: each token coloured by its probability, the ten likeliest alternatives, and what temperature, top-k, top-p and min-p do to them. Pick a different token to see where the text goes instead. Inside shows how much each of the model's layers changes each word, and what each layer would predict if the model stopped there. Steer pushes a model towards one idea and away from another while it writes, beside what it writes unpushed. Speed tests how fast a model reads and writes on this computer, and keeps the results to compare. Free.
  • 💬 Ask AI chats with a model already on this computer, run by Filescape itself: no Ollama, LM Studio or internet connection needed, and nothing you ask leaves the computer. It runs GGUF models, on the graphics chip of a Mac with Apple silicon and on the processor elsewhere. Ask AI is free.
  • Ask AI About This… in the right-click menus of Files and Storage Analysis asks about a file or folder: its size, dates and what it holds. Reading what's inside files is a tick box for each question.
  • No model yet? Get a small model… in Ask AI downloads Qwen3 1.7B (1.7 GB) from Qwen's own page, after showing you its size, licence and the memory it needs. Filescape checks the file before using it, and a stopped download carries on where it left off.
  • A new ✨ AI Models workspace (Ctrl+4) lists the AI models on this computer: what Ollama, LM Studio and Hugging Face have downloaded, model files in Downloads and in folders you add, and those in the Storage Analysis scan. Each shows its size, format, family, parameters, precision and context length, read from the file without loading it.
  • Files that are byte-for-byte copies of another model are marked, as are Ollama downloads no installed model uses.
  • filescape --cli --models PATH prints the same list.
  • Double-click a model to inspect it: its architecture, layers, heads, vocabulary, licence and parameters, each tagged with where it comes from (the file, Filescape's own count, or the publisher's notes), how its numbers are stored, and every tensor and metadata entry, searchable and sortable. PyTorch checkpoints are never opened, since they can run code.
  • A model's Health finds missing parts, files cut short by a stopped download, damaged files, unsafe formats and size labels that don't add up, and can verify Ollama and Hugging Face downloads against their checksums.
  • Will it run? estimates the memory a model needs at any context length and says whether it runs on this computer's graphics chip, split, on the processor, or not at all.
  • Click a tensor to see a histogram and statistics of its numbers, and Check the numbers in Health samples every tensor for broken values or missing data.
  • A model's Tokens show its vocabulary: which languages and kinds of text it covers, its special tokens and chat template, and every token, searchable.
  • Compare with… puts two models side by side: their facts, where their space goes, how their numbers are stored, and which tensors and metadata differ, so you can tell two compressions of one model from two different models.
  • A model's Structure shows its layers in order and draws the model as a map of its layers and tensors, coloured by what each part does or by how its numbers are stored.

Rest the pointer on a video tile and it plays there, silently. They load in the background and never download cloud files.

Alt+P shows or hides it. Videos play right in the preview panes, and on macOS sound now pauses at once and can jump to any point. Word and OpenDocument files now preview as text in both workspaces.
  • Markdown files preview formatted, with headings, lists, tables and links. Raw shows the text as written, and the preview panes remember which one you picked.
  • Right-click any part of the path above the file list, or a tab, and choose Copy Path.

  • Camera RAW photos (CR2, CR3, NEF, ARW, DNG, RAF, ORF, RW2 and more) preview on tiles, in icon views and in the panes, from the preview the camera stores in the file, with the camera, lens and exposure in the details.

  • Pictures can be looked at channel by channel, HDR and OpenEXR pictures have an exposure slider, and multilayer OpenEXR files show each layer (render pass).

What system files and folders are

  • Filescape explains the files and folders you didn't make and whose names say little: pagefile.sys, hiberfil.sys, WinSxS, System Volume Information, .Spotlight-V100, the sleep image, /proc, the systemd journal, snap and Flatpak, and about 170 more on Windows, macOS, Linux and removable drives. It says what each one is, whether it's safe to delete, and how to make it smaller safely. The guide is built in and works offline.
  • An info icon after the name in the file manager, the Storage Analysis list and the tree (hover it), a *What is this?* box in the preview pane, a note in the status bar over the map, and What Is This? in the right-click menus.
  • Free in every edition.

Freeing up cloud space

  • Free Up Space and Always Keep on This Device (Windows), or Remove Download and Download Now (macOS), in the right-click menu of cloud files and folders in the file manager, the Storage Analysis list and the tree. Filescape asks the system, which asks your cloud app: nothing is deleted, files stay in the cloud, and files with changes not yet uploaded are left alone. Keeping files that aren't downloaded asks first, saying how much would download.
  • A Reclaimable size on the Size switch maps the space freeing up would give back, and the storage breakdown says how much that is. Click it to see where.
  • On the command line, --free-up PATH and --keep PATH do the same (with Filescape Professional), and --reclaimable ranks a report by reclaimable space.
  • One file at a time is free; folders, several items at once and the Reclaimable view are part of Filescape Professional.

Cloud storage awareness

  • Filescape recognises cloud folders and drives: Google Drive, OneDrive, SharePoint, iCloud Drive, Dropbox, Box, Nextcloud, ownCloud, pCloud, MEGA, Synology Drive, and drives mounted with rclone or other FUSE tools. Nothing is installed and no provider is contacted: Filescape looks where these services keep their folders.
  • A status icon after the name of each cloud file says whether it's online only, partly downloaded, downloaded, always kept on this device or unknown; hover it for what that means and which service it belongs to. Shown in the file manager, the Storage Analysis list and the tree.
  • A storage breakdown under the map splits a scan into files not in the cloud, downloaded cloud files and data only in the cloud, with the share that is on this computer.
  • A third size, Cloud only, on the Size switch maps where the data that isn't on this computer is.
  • Stored filter chips show only online-only, downloaded, pinned or local files (Professional), and the Storage Analysis list gains Stored and other-size columns for cloud scans.
  • A new Cloud storage page in Settings, with the default size, the icons and breakdown, asking before downloads, and whether to walk into mounted cloud drives (off by default).
  • On Windows, OneDrive and other cloud placeholders no longer show as links in the file manager.

Size on disk, and cloud files that stay in the cloud

  • Filescape now reads two sizes for every file: its size on disk (what it really takes on this computer, as du and Explorer's "Size on disk" count it) and its logical size. The new Size switch above the map changes between them at once, without rescanning; everything follows it: the map, sunburst, folder list, File types, size histogram, summary, filters and the file manager's Size column. On disk is the default.
  • Cloud folders (Google Drive, OneDrive, iCloud Drive, Dropbox, Box…) now show what they use on this computer: files that are only online take almost no space, instead of their full size. Hover an item to see both sizes and whether it's online only.
  • Filescape no longer downloads online-only files behind your back: no thumbnails for them, the preview asks first, Find duplicates skips them, Compare contents compares them by size and date, and the sequence player asks before playing frames that aren't downloaded.
  • On macOS and Linux, files with several names (hard links) count once in sizes on disk.
  • Snapshots now record both sizes. Snapshots saved by earlier versions still open; they're compared by logical size.
  • The command-line report (--cli) prints both totals and counts online-only files; add --logical to rank by logical size.

A redesigned Settings window

  • Find a setting… (or Ctrl+F) searches every setting by name or by everyday words such as "zoom", "threads", "hidden files" or "licence", and takes you to it.
  • On/off settings are switches, choices are segmented buttons, and sliders show their value (drag or type it) with a reset button once changed.
  • Pictures show what you're choosing: the themes, a folder list preview that follows the columns you pick, and a small treemap drawn with the current treemap settings, with the tile styles and presets as thumbnails. The Classic cushion settings only show when that style is chosen.
  • General has a new Interface size (80% to 150%, which Ctrl + and Ctrl − also change and which is now remembered), an example for the size units, and an Updates section with your version, the last successful check, Check now and release notes.
  • Filtering keeps rules as lists you add to, edit and remove from, with Browse… for folders, warnings for rules that can't work, common patterns to add with one click, a name tester, sizes in any unit and ages in days, weeks, months or years. A summary at the top says what's skipped and when a rescan is needed.
  • Advanced has scanner thread profiles (Automatic, Low, Balanced, High, Network, Custom), a Permissions section that gives the right advice for Windows, macOS and Linux, and Diagnostics with the settings folder and system details to copy.
  • Licensing shows your edition and state at a glance, a bar for the evaluation's days left, a Paste button for the licence key, and makes clear that a perpetual licence never expires even after its updates end.
  • The footer has Restore page defaults and Restore all… (which asks first). Apply is greyed out until something changes, and Cancel or Esc undoes everything not applied.

A new look for the treemap

  • Under the Storage Analysis map, a summary shows the scanned folder, its size and file count, and the file types taking the most space, each in its map colour. It follows the filters, so with Larger than or Smaller than set you see how much space the matching files take and of which types. Click a type to highlight it.
  • The treemap has a new Modern tile style, the same look as the map on filescape.app: soft pastel tiles, names and sizes written on the tiles, and the folders on screen outlined with dark name tags. The cushion look is still there as Classic cushion under Settings > Treemap > Tile style.
  • Filescape has its own icon, the tile-grid logo from the website, in the window, the taskbar and the Dock.

Files workspace

  • Filescape now opens as a file manager. Browse your drives, folders and network shares straight away, with no scan. It has:
    • a sidebar with Home, Desktop, Documents, Downloads and the rest, favourites, drives with their space, and recent folders;
    • tabs that are restored next time;
    • Back, Forward and Up;
    • a path you can click or type in (Ctrl+L), including \\server\share paths;
    • a sortable Details list with a filter box and type-to-select;
    • Shift and Ctrl selection.

  • A full file manager. Copy, cut and paste (Ctrl+C, Ctrl+X, Ctrl+V), drag and drop, F2 to rename and Delete to send to the Recycle Bin or Trash now work in Files. Drops move items on the same drive and copy them to another, as in Explorer and Finder, and the label by the pointer says which.
  • Undo and name clashes. Ctrl+Z undoes copies, moves, renames, new items and Move to Trash, putting deleted items back from the bin. When a copy or move meets a name that's taken, Filescape asks: Replace, Keep Both, Skip, or Merge for folders.
  • Servers: SFTP, FTP and WebDAV. Browse, copy to and from, rename and delete on servers as if they were drives, and analyse their folders. Connect to Server… saves them in the sidebar. SFTP checks the server's identity and signs in with your SSH agent, key files or a password; passwords are only ever kept in the system keychain, and only if you ask. FTP and plain-http WebDAV are marked as not encrypted.
  • Image sequences and a sequence player. Numbered frames (shot.1001.exr, shot.1002.exr…) show as one row with their range and any missing frames, and copy, move, delete and drag as one item. Double-click one to play it from memory, with a timeline, loop, ping-pong, frame rates from 23.976 to 60, exposure and colour transforms (sRGB, Rec.709, Cineon log). Select two and press Enter to compare them with a wipe. EXR, DPX, PNG, TIFF and the other image types all play.
  • Two panes (Ctrl+\\): two folders side by side or one above the other, each with its own tabs, sort and filter. Drag between them, or press Shift+F5 to copy and Shift+F6 to move to the other one.
  • Favourites. Drag a folder onto the sidebar to bookmark it; nothing is moved. Reorder them by dragging, rename them, and sort them into groups. Pinned folders become favourites.
  • Quick Look and a preview pane. Press Space for a large preview, or Alt+P for a preview pane, with zoom and pan. Images (including OpenEXR and HDR) and text files.
  • Four views. Details, Icons, Columns (the folders above this one at the left, as in Finder) and Gallery (a large preview over a strip of pictures), from the buttons at the bottom right of the list. Icons and Gallery show pictures of images, videos and PDFs. Each folder remembers its own view, sort and grouping.
  • Groups. View > Group By puts the Details list under headings by type, date or size.
  • Rename many items at once. Select several items, or a sequence, and press F2: find and replace (with regular expressions), change case, add numbers or change the extension, with every new name shown before anything changes.
  • Compare and sync folders. With two panes, View > Compare Folders… shows what's only on one side, newer on one side or different, then copies one way, both ways or mirrors the left onto the right. Replaced and deleted items go to the bin, and Undo reverses a sync.
  • Search subfolders. 🗐 beside the filter searches the folder and every folder below it, and ☆ keeps the search in the sidebar.
  • Colours, tags and notes. Give items a colour, tags and a note from the right-click menu. The sidebar's Tags shows everything with a tag.
  • Open With your own apps. Add the programs you use for each type of file (Nuke, RV, a text editor) and open items in them from the right-click menu.
  • Redo (Ctrl+Y or Ctrl+Shift+Z) after an Undo, and F6 to move the keyboard to the sidebar and back.
  • LUTs in the sequence player. LUT… shows frames through a .cube file.
  • Archives. Open zip, 7z and tar archives like folders, preview what's in them, and take things out with Extract Here, Extract To…, copy and paste or a drag.
  • Pause and queue. Copies and moves show their progress in the status bar, can be paused, resumed and stopped, and ones started while another runs wait their turn.
  • Changes made by other programs show up in the list by themselves, without F5.
  • Video, PDF and sound previews. A frame from a video and a PDF's first page from the system's thumbnailers, and sound files play in the preview.
  • A smarter address bar. Suggestions as you type, Tab completion, %VAR% and $VAR, > for commands and @ for favourites. Each part of the path takes drops and has a menu of the folders inside it.
  • New menu. New folders and small valid starter files (text, Markdown, JSON, XML, CSV, scripts), plus your own templates: put any file or folder in the templates folder and New copies it.
  • Network & Remote. Mapped drives (including offline ones), network mounts, saved servers and Connect to Server… for SMB shares. The system asks for passwords; Filescape never sees them.
  • The analysis dock (Ctrl+J) shows the treemap or sunburst of the folder you're in, under the list. Once a folder or drive is analysed, every folder inside it shows its treemap straight away as you browse, with no rescanning.
    • Analyse Folder scans in the background while you keep browsing.
    • Refresh Analysis rescans just one folder inside a bigger analysis.
    • The dock can follow the open folder, follow the selected folder, or stay pinned to one folder.
    • Selecting in the list outlines the item on the map, and clicking a tile selects it in the list. Tiles have the same right-click menu as the list.
    • A line above the map shows the folder's size, file and folder counts, its largest file and subfolder, and whether it has changed since it was analysed. The legend under the map highlights a file type when you click it.

  • Storage Analysis is still the Filescape you know, with everything in it. Ctrl+1 and Ctrl+3 switch between the two workspaces, and each keeps your place.
  • A new look. It has:
    • calmer panel colours in both themes, and one accent colour;
    • grouped toolbar buttons;
    • proper tabs, which you can drag to reorder;
    • resizable columns;
    • Comfortable or Compact rows (View menu);
    • a status bar that shows background work.
  • Folder sizes from the last scan show in the Files list.
  • Big folders and slow network drives never freeze the window: folders are read in the background, and a share that takes a while says so and can be cancelled.

Linux distributions in the sidebar

  • On Windows, your WSL distributions are listed under Linux in the sidebar, as in Explorer. Click one to browse its files.

Windows' own right-click menu

  • On Windows, Show More Options at the bottom of an item's right-click menu (or Shift+F10, or Shift+right-click) opens the menu Explorer shows, with what other apps add to it: 7-Zip or PeaZip, Notepad++, PowerToys, antivirus scanners, Send to and the rest.

Show in Files

  • Show beside the filter in Files keeps only some kinds of file (Audio, Video, Images, Documents…), and with 🗐 gathers them from every subfolder.
  • The preview pane counts a selection of several items by kind, with sizes. Click a kind to preview one of them.
  • Crashes are saved to crash.log in Filescape's settings folder, and on Windows a message says what happened, so a crash can be reported.

Fixes

  • Menus have icons, in a column of their own so the names line up.
  • File names on map tiles are easier to read. They sit on a dark backing and get bigger as you zoom in.
  • pagefile.sys, swapfile.sys and hiberfil.sys aren't counted as Programs any more. They're Windows' memory saved to disk, and now count as Other.
  • Previews of UTF-16 text files, such as PowerShell output, show the text instead of "No preview". PDFs on Windows show their first page without needing a PDF app's thumbnails.
  • The File Manager toolbar no longer overlaps itself on a narrow window. Back, Forward, Up, the path and the filter now sit on the pane's own bar above the tabs, and on a narrow window the toolbar's buttons show only their symbols.
  • Resizing the window on Windows no longer makes the panels shake. Filescape now draws with OpenGL there. DIRMAP_RENDERER=wgpu brings back DirectX 12.
  • Rename no longer replaces a different file whose name differs only in capital letters (readme → README) on Linux and on case-sensitive Mac disks.
