Nothing in a file is ever run

Previews only read files, never change them. Macros, scripts, formulas and links are never run or followed, HTML mail is shown as plain text so tracking pictures never load, and patient details in medical scans are never shown. Everything is read by Filescape itself or your system's own decoders, on your computer. Files that are only in the cloud aren't downloaded for a thumbnail.
