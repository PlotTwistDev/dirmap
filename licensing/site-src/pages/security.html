Security and privacy

Filescape works on your computer. This page lists everything it sends over the internet, what it keeps, and how it handles passwords, licences and downloads. It describes the app as it is today; if something here changes, this page changes with it.

In short

  • Scanning, the disk map, previews, file operations and Ask AI run on your computer. Your files, file names and questions are never uploaded.
  • The app goes online for four things only: licensing, the update check, an AI model you choose to download, and servers you connect to. Each is described below.
  • There is no analytics, crash reporting or advertising in the app, and no account is needed to use it.

Your files

Filescape reads your drives to measure and preview them. Previews are drawn by Filescape's own code; it never runs a file, a macro or a script to show it. Nothing it reads is sent anywhere.

Deleting is the one thing that can lose data, so Filescape treats it carefully:

  • Move to Trash (Recycle Bin on Windows) can be undone with Ctrl+Z, as can copies, moves, renames and new items. Filescape remembers the last 30.
  • Delete Permanently skips the bin and can't be undone. Filescape always asks first and says how much is involved.
  • Replacing a file in a name clash moves the old one to the bin, so Undo can bring it back. On a server there is no bin, so replacing or deleting there is permanent, and Filescape asks first.
  • Cloud folders (Google Drive, OneDrive, iCloud Drive, Dropbox): Free Up Space removes only the copy on this computer; the file stays in the cloud. Deleting a file there deletes it from the cloud too, as it would in Explorer or Finder.

Filescape comes with no warranty, and no tool replaces a backup. Please keep one. See the terms.

Local AI

Ask AI and the Lab run models inside Filescape, on your processor or graphics card. Your questions, the files you attach and the answers stay on your computer, and work without an internet connection. File text you attach is given to the model as data, marked off from your question, and Filescape shows which files an answer used.

Downloading a model happens only after you agree to it. The starter model comes from a fixed version of its publisher's page on Hugging Face, and Filescape checks its SHA-256 checksum before using it. Hugging Face sees an ordinary download from your computer.

Servers and passwords

  • SFTP: the server's key is checked against your ~/.ssh/known_hosts and Filescape's own list. A new server's key is shown to you before anything is sent, and a server whose key has changed is refused.
  • Signing in tries your SSH agent and key files before a password.
  • Passwords you save are kept in your system's own store: Keychain on macOS, Credential Manager on Windows, the Secret Service on Linux. They're never written to Filescape's settings.
  • Plain FTP and http WebDAV send passwords and files unencrypted, so Filescape asks before connecting that way. Use SFTP, FTPS or https where you can.

What the app sends, and when

  • Update check, at each launch: asks api.filescape.app for the latest version. It sends nothing about you, your computer or your licence. Turn it off in Settings > General.
  • Activating Pro: the serial number, an activation ID, an anonymous computer identifier (a one-way hash of the computer's system ID), the app version and the operating system's name.
  • Licence check, about once a week while you're online: the activation ID and the same computer identifier. Being offline never turns Pro off; the check just waits until you're back online.
  • Offline activation: the same request, saved as a file you carry to a computer with internet access yourself.
  • AI model downloads and servers you connect to, as above.

Licences are signed certificates (Ed25519) that the app checks with a public key built into it, so a licence can't be forged or edited, and the app doesn't need to ask the server each time it starts.

Buying

Payments are taken by Paddle, our reseller and Merchant of Record. Your card details go to Paddle, never to Filescape. Paddle tells us your name, email address and the transaction ID so we can send your licence. On filescape.app, Paddle's checkout script loads only when you start to buy.

The website sets no cookies of its own, uses no analytics or advertising trackers, and serves its fonts itself. The full list of what's kept is in the privacy policy.

Is the download genuine?

  • macOS: not yet signed with an Apple Developer ID or notarised by Apple, so macOS asks you to allow it the first time. How to open it on a Mac.
  • Windows: not yet code-signed, so SmartScreen may say it doesn't recognise the app.
  • Linux: AppImage, .deb, .rpm and .tar.gz, unsigned.

Download Filescape only from filescape.app or downloads.filescape.app. Apple notarisation and Windows code signing aren't in place yet; this page will say when they are.

Reporting a security problem

If you find a way Filescape could expose someone's files, passwords or licence, please tell us through the contact form and choose Privacy request. We'll reply, fix it and say what changed in What's new.
