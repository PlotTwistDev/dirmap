See what's inside a model

Double-click a model for its architecture, layers, heads, vocabulary, licence and parameters. Each fact says where it comes from: the file itself, Filescape's own count, or the publisher's notes.

  • Will it run? Memory needed at any context length, and whether it fits on this computer's graphics chip

Will it run?

Know before you load it

Filescape works out the memory a model needs at any context length and says whether it runs on this computer's graphics chip, split between the graphics chip and the processor, on the processor alone, or not at all.

  • Health checks for missing parts, files cut short and damaged data
  • Verify Ollama and Hugging Face downloads against their checksums
  • Check the numbers samples every tensor for broken values
Ask AI and the Lab

Chat with a model offline, and watch it think

Ask AI runs GGUF models inside Filescape itself, with no Ollama, LM Studio or internet connection needed. On a Mac with Apple silicon it uses the graphics chip; on Windows and Linux, the processor. Right-click a file or folder and choose Ask AI About This… to ask about it.

The Lab shows what a model would write next and how sure it is: each token coloured by its probability, with the ten likeliest alternatives. Pick another to see where the text goes instead.

  • See what temperature, top-k, top-p and min-p do to the choices
  • Look inside each layer, steer a model toward an idea, and test its speed
  • No model yet? Get a small one (Qwen3 1.7B) after seeing its size, licence and memory needs

Your questions stay on your computer

Models run on your own hardware and nothing you ask is sent anywhere. Filescape reads only the part of a model file that describes it, and never opens PyTorch checkpoints, since loading one can run code. Models that are only in the cloud are listed but not downloaded. Answers come from the model, not from Filescape, and small models can be wrong.
