Know whether it will run before you load it

Will it run? reads this computer's processor, memory and graphics card, works out the memory a model needs at any context length, and gives two answers: how it runs in Filescape, and how it runs in apps such as Ollama and LM Studio. Once you've tested its speed in the Lab, the measured speed is shown too.

  • On a Mac with Apple silicon, Filescape runs models on the graphics chip
  • On Windows and Linux it uses the graphics card when its drivers support Vulkan, and the processor otherwise
  • Smaller versions of the model, and what they would need

Your questions stay on your computer

Models run on your own hardware and nothing you ask is sent anywhere. Filescape reads only the part of a model file that describes it, and never opens PyTorch checkpoints, since loading one can run code. Models that are only in the cloud are listed but not downloaded. Answers come from the model, not from Filescape, and small models can be wrong.
